Almacenamiento local activo. La sincronización requiere configurar la clave pública de Supabase.

Configurar Supabase

Abre js/supabase-config.js y pega la URL de tu proyecto y la clave pública anon/publishable. Después ejecuta supabase/schema.sql en el SQL Editor de Supabase y añade la URL publicada de esta PWA a Authentication → URL Configuration → Redirect URLs. Nunca uses la clave service_role en el navegador.
